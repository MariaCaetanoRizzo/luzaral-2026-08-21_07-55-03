# Luzaral
# Teste de Diversos Tipos de Luz 
- Repositório para mandar e criar os projetos da aula de LP
- Alunos produtores do projeto: Arthur Paixão Serafim, Maria Caetano Rizzo, Rihan de Jesus
- Nosso projeto foca em mostrar como cada tipo de luz da Unity reage em relação ao ambiente.
